# Contribuindo

## Antes de commitar
* Teste o programa: python src/main.py
* Faça as análises(Temos hook do pre-commit): pylint src  &  radon cc src -s
* Elabore uma mensagem objetiva para seu commit 

## Padrões de código
* Utilize nomes claros e explicativos, caráctere não tem custo, não abrevie exageradamente.
* Funções, váriaves, módulos e outros devem ser formatados em camelCase.
* Docstrings não são obrigatórios, porém métodos não triviais devem ser intuitivos ou explicados.
* Limite de linhas é 130 caracteres.
